# DT AI季度探索项目 — 7项模板要求

> 基于《AI季度探索项目立项与管理办法》
> 当用户属于DT（数科平台）时，Step 4使用此模板。

## 模板结构

1. **项目名称**：明确、简洁
2. **组队人员**：姓名+部门，<=3人，注明专职/兼职
3. **申请金额**：最高30万，仅采购成本（不含人力）
4. **预期业务价值**（<=500字）：
   - 一句话核心价值
   - 详细展开
   - 融入段永平商业过滤：
     - 怎么赚钱/省钱/提效？（量化）
     - 10年后这个需求还在吗？
     - 别人能复制吗？壁垒在哪？
5. **成功标尺**：具体可衡量，每个标尺包含：
   - 目标值
   - 统计口径
   - 数据来源
6. **项目计划**：
   - 立项 → 启动(DTM录入) → 结项(成果汇报)
   - 通常3个月周期
7. **涉及的AI相关技术**：
   - 探索哪些AI技术
   - 如何形成知识沉淀

## 答辩形式

15分钟（10分钟陈述 + 5分钟Q&A）

## 关键约束

- 经费仅限采购成本，不含人力成本
- 不超过3人组队
- 需要进入DTM系统录入
