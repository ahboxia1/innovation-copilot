# 千丁蜂巢/敏捷立项 — 8项模板要求

> 基于《创新项目敏捷立项机制》+《蜂巢创新大赛设计方案》
> 当用户属于千丁时，Step 4使用此模板。

## 模板结构

1. **项目一句话**：产品 + 价值
2. **问题 Why**：为什么值得做
3. **用户与场景 Who**：目标用户 + 使用场景
4. **解决方案 What**：核心能力（<=3点）
5. **核心价值 Value**：必须量化
   - 效率提升 / 成本降低 / 风险降低
   - 需要有具体数字
6. **验证路径 POC**：
   - 2-4周 / 2-3人
   - 验证方式说明
7. **成功标准 Success**：
   - Demo完成 / 客户试用 / 付费意向
   - 每项需要有明确判断标准
8. **资源需求 Resource**：
   - 人员 / 时间 / AI算力 / 数据

## 答辩形式

8-10分钟Pitch

## 关键约束

- POC周期短（2-4周），强调快速验证
- 核心价值必须量化（不允许"提升效率"这种模糊表述）
